# pocketwise-student-budgeting
PocketWise – Student Budgeting and Expense Management

Project Overview

PocketWise is a student budgeting and expense management project designed to help students manage their money, track daily expenses, and make better financial decisions.

Problem Statement

Many students struggle to manage limited finances because they do not consistently track their spending or plan their budgets. PocketWise aims to provide a simple way to monitor expenses and manage available funds.

Project Objectives

- Help students create and manage budgets.
- Allow users to record and monitor expenses.
- Help students understand their spending habits.
- Encourage responsible financial management.
- Provide a simple and user-friendly experience.

Project Structure

- "prototype/" – Contains the PocketWise application prototype.
- "google-apps-script/" – Contains the Google Apps Script files for spreadsheet integration.
- "docs/" – Contains project documentation and presentation materials.
